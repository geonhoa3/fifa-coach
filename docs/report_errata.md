# 경기 리포트 정오표

2026-10-08 작성. 대상: 경기별 코칭 리포트(match08~29, 22개)와 코칭 카드.

## 왜 생겼나

리포트는 공의 위치를 "우리가 공격하는 방향" 기준으로 바꾼 좌표(i)로 썼다. i=0이 우리 골대, i=15가 상대 골대다.
그런데 공격 방향 계산에 오류가 있었다. 경기 도중 방향이 3~11번씩 잘못 뒤집혀서, 그 구간에서는 우리 진영과 상대 진영이 바뀌어 기록됐다.

2026-10-07에 방향 계산을 "하프타임에 한 번만 바뀐다"는 조건으로 고쳤다 (커밋 `25f4a4e`, `f1862f6`, `c4ccfe9`).
고친 뒤 골이 들어간 골대와 스코어보드를 맞춰 보면, 골 123개 중 일치하는 골이 88개에서 122개로 늘었다.

## 바뀌지 않는 것

- 골, 실점, 최종 스코어, 골 시각: 스코어보드 OCR로 판정해서 방향과 관계없다.
- 넥슨 API로 만든 분석: 슛 좌표, 구역별 전환율, 패인 분석은 영상 데이터를 쓰지 않는다.

## 코칭 카드

코칭 카드(`coaching_card.png`)를 2026-10-08에 새 데이터로 다시 만들었다.

- **프로 대비 약점 구역**: 예전과 같은 구역이 뽑혔고 수치만 조금 달라졌다 (예: 페널티 부근 중앙 슛 도달률 차이 −10%p → −14%p).
- **첫 영상 대비 변화**: 크게 달라졌다. 예전 카드는 대부분 구역이 "개선"이었고 빈도 변화가 +600~1400%였지만, 새 카드는 빈도 변화가 −26~+55%이고 개선과 악화가 섞여 있다. 예전 카드의 "전반적으로 개선됐다"는 결과는 근거로 쓰지 않는다.

## 확인 방법

예전 결과(방향 수정 전)와 수정 후 결과를 같은 장면끼리 맞춰, 리포트에 나온 시각 앞뒤 1초 안에서 공의 위치(i)가 우리 진영(i<8)인지 상대 진영(i≥8)인지 비교했다.
