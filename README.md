# FIFA Coach — FC 온라인 데이터 분석 코칭 시스템

> FC 온라인(EA SPORTS FC ONLINE) 경기를 **영상(OpenCV)** 과 **넥슨 공식 API** 로 분석해, 데이터로 개인화 피드백을 만드는 프로젝트.

---

## 한 줄 요약

미니맵 CV 파이프라인으로 시작 → **넥슨 공식 API를 발견하며 접근법을 재평가** → **내가 세운 코칭 가설들을 218경기 데이터로 직접 검증(대부분 반증)** → *"무엇을 만들 수 있나"* 가 아니라 *"무엇이 실제로 유효한가"* 를 데이터로 판단한 기록.

> 이 저장소의 핵심 가치는 **완성된 제품**이 아니라 **자기 가설을 데이터로 반증하고 방향을 판단한 과정**에 있다.

---

## 핵심 서사 — 만들고, 검증하고, 판단하다

1. **만들었다** — 미니맵 CV로 게임 상태를 추출하고 코칭 리포트를 생성하는 파이프라인 구축 (OpenCV + 통계).
2. **한계를 인정했다** — 넥슨 공식 API가 골 시각·슛 좌표·선수별 스탯을 **정확히** 제공. CV의 이벤트 검출(골 오검출·자릿수 오독 등)이 **불필요하고 부정확**함을 확인하고 API로 전환.
3. **내 가설을 반증했다** — "골 넣은 직후 실점이 잦다", "문 앞까지 가고도 슛을 안 쏜다" 등 **5개 코칭 가설**을 218경기로 검증. **노출 시간·상대 등급을 보정하니 전부 성립하지 않음** — 작은 표본이 만든 착시였다.
4. **진짜 원인을 찾았다** — 낮은 랭크는 실력이 아니라 **랭크 판수 부족** 때문(공식친선 96% vs 공식경기 4%). 지표는 상위 등급과 대등했다.
5. **판단했다** — 데이터로 제품 시장성이 약함을 확인하고, 개인 분석 도구로 방향을 재설정.

---

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 영상 분석 | OpenCV — 미니맵 게임상태 추출, 팀/공/조작선수 dot 검출, 이벤트 분류 |
| 가치 평가 | xT(expected threat) 격자 모델 |
| OCR | EasyOCR — 스코어보드 골·스코어 자동 검출 |
| API | 넥슨 Open API — 매치 상세·선수별 스탯·슛 좌표 수집/분석 |
| 데이터 분석 | 베이스라인·노출 보정 hazard 분석, 상대 등급 통제 비교, 슛 히트맵 |
| 객체 검출 | YOLOv8 (미니맵 dot 검출, 학습 데이터 별도) |

---

## 배운 것 (이 프로젝트가 남긴 원칙)

- **기계를 만들기 전에, 찾으려는 게 존재하는지 하루짜리로 먼저 확인한다.** CV를 몇 달 만든 뒤에야 "찾을 게 있나"를 검증한 건 순서가 거꾸로였다.
- **작은 표본·자의적 구간은 없는 패턴을 만든다.** 사건 클러스터를 주장하기 전 반드시 **베이스라인 / 노출 시간 보정**을 한다.
- **집계 지표는 서술은 해도 처방은 못 한다.** "무슨 일이 있었나"는 알려주지만 "왜 그랬고 뭘 바꿔야 하나"는 못 알려준다.
- **정확해지는 것과 쓸모 있어지는 것은 다르다.**

## 저장소 구조

```
src/                    # CV 파이프라인 (미니맵 추출 → 이벤트 → xT → 리포트)
  extract_game_state.py #   미니맵 → 게임상태 CSV
  detect_events.py      #   이벤트(패스/슛/골) 분류
  detect_goals_ocr.py   #   스코어보드 OCR 골 검출
  grid.py / xt_model.py #   격자 + xT 가치맵
  coaching_report.py    #   코칭 리포트 생성
  fetch_api.py          #   넥슨 API 매치 수집·캐싱
  prescription.py       #   프로 경기 대비 처방 분석
fetch_api / dashboard / meta_gap / lowtier_gap / ...   # API 기반 분석 스크립트
train_yolo.py           # YOLOv8 학습
```

주요 API 분석 스크립트(저장소 루트):
- `dashboard.py` — 개인 대시보드(슛 히트맵·구역별 전환율·시간대/슛수 승률)
- `meta_gap.py` / `lowtier_gap.py` — 대상 유저 vs 상위등급 메타 갭
- `pull_striker_test.py` / `check_formation.py` — 포메·선수 배치 A/B 분석
- `ranked_vs_friendly.py` / `newseason.py` / `why_lost.py` — 경기별 진단

---

## 실행

```bash
pip install -r requirements.txt
```

넥슨 API 사용 스크립트는 [넥슨 Open API](https://openapi.nexon.com) 키가 필요하다.
키는 코드에 넣지 말고 저장소 루트에 `.nexon_key` 파일(한 줄)로 두면 자동으로 읽는다. (`.gitignore` 처리됨)

```bash
python dashboard.py                 # 개인 대시보드
python why_lost.py <상대닉네임>       # 특정 경기 패인 분석
```
